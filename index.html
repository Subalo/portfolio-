01 / FPGA + SOFTWARE

Smart Lock System93 / 100

A face-recognition access system.
Hardware and software, working together.

Built on the PYNQ-Z2, this system combines Python and OpenCV on the processing system with a VHDL stepper-motor controller in programmable logic. Sensors, keypad access and Telegram alerts complete the control loop.

Inside the engineering +

Hardware–software integration

A custom VHDL motor controller is packaged as IP in Vivado. Python communicates with the programmable logic through an overlay and AXI GPIO interfaces.

Verification

Vivado simulations check the stepper phase sequences. System checks in Jupyter cover startup, access attempts, sensor behavior and alert handling.

DIGITAL LOGIC PROJECT

02

Digital Safe

Access control,
built from logic.

An electronic safe built from shift registers, flip-flops, logic gates and timers. The logic-based implementation validates the input sequence, controls the unlock interval and triggers an alert after repeated incorrect attempts.

An Arduino implementation also explores a programmable approach to the same functionality.

  • Digital logic
  • Multisim
  • 555 timers
  • Arduino / C++
